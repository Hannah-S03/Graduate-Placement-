Accessibility statement

Draft. Update this statement after the accessibility testing done before launch.

We want everyone to be able to use this hub. We aim to meet WCAG 2.2 level AA. The hub can be used with a keyboard, every form field has a label, messages are announced to screen readers, and it works on phones, tablets and computers.

If you have trouble using any part of the hub, or need information in another format, contact us and we will help.
